# DTS Taglish staff showcase

Start with **DTS-Showcase-Production-Book.pdf** for the complete presenter guide, or open **storyboard.html** in a browser to review the visuals.

The package contains a 32-minute staff demonstration, 32 matched scenes, 96 screen-action cues and a separate three-minute overview. It covers registration through release, exceptional paths, regular and Special Reports, personnel scheduling, analytics, administration, recovery, Workflow Designer and measured stress-test results.

## Present or rehearse

1. Extract the whole ZIP before opening the HTML storyboard. Keep the `assets` and `boards` folders beside it; no web server or internet connection is needed.
2. Select **Open presentation frame**, then use Previous/Next. Press F11 for browser fullscreen. Expand notes during rehearsal.
3. Read only Spoken narration aloud. Screen beats and presenter cues guide the demonstration or recording.
4. Use the verified enrolled role cast in the book. Prepare one hero document for the full lifecycle, plus separate exception and report examples.
5. Retain scene IDs when changing timing. The 32-minute schedule includes demonstration holds; allow another 5-10 minutes for staff questions.

## Production notes

The 32 stills are reference images with planned editorial overlays. Different sample records illustrate different stages. Final action recordings should follow one consistent tracking number through the ordinary lifecycle. The script has 3,279 spoken words; the three-minute cut has 298 words. Timings are estimates pending the actual voice recording and demonstrations.

Use authentic DTS action recordings for product UI. The JSON contains scene-specific prompts for assembling or generating editorial treatment around those recordings. Keep captions in the lower 17 percent and crop recordings so controls remain readable. Generic generated footage can illustrate an opening context, but it must not invent application actions or features.

The Workflow Designer scene explicitly describes drafting, publication and simulation. Clearance and release are separate; linked files remain external; measured capacity is qualified by the tested workload and machine. Performance figures refer to the verified 16 October 2026 run.

This delivery contains script, storyboard and presentation planning assets. Narrated video production is a subsequent step. Application source files and the original business database were not changed to create it. The ZIP excludes internal capture tools, databases, credentials and QA scratch files.

# Graph overflow, document page sizes, and dense schedules

## Changes

- Monthly charts now use a wrapping grid with a minimum column width. January 2025–December 2026 retains all 24 months in both charts, within their own cards and the print sheet. Responsive chart cards also fit phone widths.
- Dashboard offers **Documents per page: 25, 50, 100** next to the record count. Changing the size resets to page one and clears selections. Counts, pagination and Select all visible use the chosen size. The staff action list uses the same size and has its own selector. Reference-list page sizes stay at 25.
- Printed table rows stay together across page breaks, including long personnel and schedule descriptions.
- Added reproducible schedule seeding and browser regression scripts in `test/seed-stress-schedules.js` and `test/overflow.ui.test.js`.

## Repeat

With the demo servers running, `node test/seed-stress-schedules.js` adds schedules to port 3131. For port 3130, set `$env:SCHEDULE_DEMO_PORT='3130'` first. The seeder supports only those two isolated demo ports and skips already-seeded records by their mock remark key.

With Playwright available to Node and Edge installed, run `node test/overflow.ui.test.js`. It tests port 3131 and saves evidence locally. Refresh open browser tabs to load the updated JavaScript and CSS; server restart is unnecessary for these static-file changes.
